# Análisis de Ventas - Gestión Colaborativa con Git, GitHub y Jira

## Descripción del proyecto

Este repositorio corresponde al Trabajo Práctico de la materia Organización Empresarial de la Tecnicatura Universitaria en Programación a Distancia.

El proyecto tiene como objetivo aplicar herramientas de gestión colaborativa, control de versiones y organización empresarial mediante el uso de Jira, Git, GitHub y Google Colab.

## Escenario elegido

Escenario B: Análisis de Ventas de una Pequeña Empresa.

El equipo trabajó con datos simulados de ventas comerciales para calcular indicadores básicos y generar resultados reproducibles.
