# Análisis de Ventas - Gestión Colaborativa con Git, GitHub y Jira

## Descripción del proyecto

Este repositorio corresponde al Trabajo Práctico de la materia Organización Empresarial de la Tecnicatura Universitaria en Programación a Distancia.

El proyecto tiene como objetivo aplicar herramientas de gestión colaborativa, control de versiones y organización empresarial mediante el uso de Jira, Git, GitHub y Google Colab.

## Escenario elegido

Escenario B: Análisis de Ventas de una Pequeña Empresa.

El equipo trabajará con datos simulados de ventas comerciales para calcular indicadores básicos y generar resultados reproducibles.

## Estructura del repositorio

- `/datos`: contiene el dataset utilizado para el análisis.
- `/scripts`: contiene el script desarrollado en Python.
- `/resultados`: contiene los archivos generados por el análisis.
- `README.md`: documentación general del proyecto.
- `.gitignore`: archivo para excluir elementos innecesarios o sensibles.

## Herramientas utilizadas

- Jira para la gestión de tareas.
- Git para el control de versiones.
- GitHub como repositorio remoto.
- Google Colab como entorno de trabajo.
- Python para el análisis de datos.
